# ParaGUIBench

GUI Agents》**（超越串行交互：GUI 智能体并行执行与协调基准）的官方项目仓库。

> 当前仓库仅作为项目主页。论文在 arXiv 发布后，我们将在此补充论文链接。基准任务、并行基础设施、

## 项目概述

现有 GUI 智能体通常以串行的“感知—决策—动作”循环执行长时程任务，每一步都会产生高成本的大多模态
模型推理，且性能会随上下文增长而下降。ParaGUIBench 旨在研究：多个 GUI 智能体能否在相互隔离的
桌面环境中协调工作，并行完成可分解的任务负载。

ParaGUIBench 包含三个核心组成部分：

- **原生并行基础设施。** 每个 GUI 工作器（worker）运行于独立的 Docker 容器中，并拥有完整的
  Ubuntu 桌面环境；所有工作器通过共享挂载目录交换中间产物。基础设施支持配置并发工作器数量，
  并在每次运行前恢复各容器的初始状态。
- **基准数据集。** 基准共包含 233 个任务，覆盖两个领域下的六类任务。每个任务均标注了对应的并行
  执行模式：`parallel_independent`、`parallel_dependent` 或 `serial`。
- **评测系统。** 基于规则的评测器通过文本答案或最终环境状态判断任务是否完成，并同时报告任务
  成功率、步数缩减比（step reduction ratio）、并行度和 Token 成本。

我们还提出了 **ParaGUI**，一种 planner–worker 架构的 GUI 智能体。规划器将长时程任务分解为可并行
执行的子任务，将其分派给多个并发工作器，汇总工作器返回的结果，并决定是否继续下一轮调度。在
ParaGUIBench 上，ParaGUI 的任务成功率达到 **46.4%**，比最强串行基线 Claude Sonnet 4.6 高
**12.9 个百分点**；在默认视觉历史配置下，其关键路径步数约为该基线的一半，Token 用量不到一半。
